# Love Piano landing site

Static site for the Love Piano app, served by GitHub Pages.

- Landing: https://ngocquang.github.io/love-piano-app-landing/
- Privacy Policy: https://ngocquang.github.io/love-piano-app-landing/privacy/
- Terms of Use: https://ngocquang.github.io/love-piano-app-landing/terms/
- Support: https://ngocquang.github.io/love-piano-app-landing/support/

Plain HTML and CSS. No build step. Push to `main` to deploy.

Preview locally:

```bash
python3 -m http.server -d . 8000
```
